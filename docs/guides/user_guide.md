# User Guide

## Getting Started

### Installation

\`\`\`bash
pip install -r requirements.txt
\`\`\`

### Quick Start

1. Download data:
   \`\`\`bash
   make setup-data
   \`\`\`

2. Train model:
   \`\`\`bash
   make train
   \`\`\`

3. Run app:
   \`\`\`bash
   streamlit run app.py
   \`\`\`

## Configuration

Edit \`config/config.yaml\` to customize training parameters.
